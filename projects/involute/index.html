02 / Behind the curve

One simple motion.
A beautiful result.

Imagine a string wrapped around a circle. Keep it taut as you unwrap it. The free end, P, traces an involute. The string always leaves the circle at a tangent, T.

The unwound angle θ measures how far you have turned around the circle. The polar angle φ locates P as seen from the centre, O. They are different angles.

Centre distanced = r √(1 + θ²)θ in radians · string length = rθ
Follow the coordinates

For a base circle of radius r and an unwound angle θ in radians:

x = r(cos θ + θ sin θ)
y = r(sin θ − θ cos θ)
φ = θ − arctan θ

The table solves the last equation for θ at each polar angle, then calculates the centre distance. Values are rounded only for display. The plot fits the curve to the available space as the radius changes.
