Modifications, September 2026:
These are JavaScript browser adaptations with new responsive interfaces,
keyboard/touch controls, bounded puzzle solvers and regression tests.
Tic-Tac-Toe extends the original board-tree prototype into a playable game
with minimax computer play. These pages do not execute the original Windows
binaries or Borland graphics programs. See README.md in this website's source
repository for implementation details and links to the original work.

2048 and DOOM are linked existing projects and retain their separate licenses.

Snake, Minesweeper and Connect Four are original browser implementations
added to this collection in September 2026, licensed under Apache-2.0.
They are not adaptations of the original Game Algorithms repository.
