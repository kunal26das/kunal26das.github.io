01 / What I doPlatform engineering

The layer beneath the features.

Most of my work sits underneath the product: the structure, tooling and safety nets that let a mobile team ship quickly on every platform.

01

Architecture & build systems

Multi-module Gradle, monolith decomposition and layering the build enforces. Version catalogues, convention plugins and one source of truth for versions across npm, Gradle and Xcode.

02

Cross-platform foundations

React Native hosted inside native apps, typed contracts shared across Kotlin, Swift and TypeScript, and Kotlin Multiplatform code that runs on both Android and iOS.

03

Reliability & performance

Crash and app-freeze programmes, startup measured from tap to usable screen, and monitoring behind interfaces so vendors can change without touching product code.

04

Release engineering & tooling

Release trains and hotfixes, over-the-air delivery with guardrails, and debug tooling that lets anyone on the team test deep links and feature flags on a real device.

05 / AboutBengaluru, India

Hello, I’m Kunal.

I’m a senior mobile platform engineer in Bengaluru. I started as a founding Android engineer, and today I work across Android, iOS and React Native, usually on the parts other engineers build on: module structure, build and release tooling, the bridge between native code and React Native, and the monitoring that says when something is wrong.

I like leaving a codebase simpler than I found it. At Licious that has meant decommissioning six third-party SDKs and deleting a 71-file local-database layer once it was clear nothing in it needed to survive a restart, all while the app kept shipping.
